# Shift Summary Report for Director (Сводный рапорт смены)

Модуль для Odoo 19, автоматизирующий формирование и отправку сводного электронного документа **«Рапорт смены»** директору завода после подведения итогов смены.

## 🚀 Основные возможности

1. **Автоматический расчёт ключевых метрик:**
   - **Общий объем выпуска деталей** (Total Produced Volume)
   - **Коэффициент выполнения плана** в процентах (%)
   - **Процент брака за день** (%)
   - **Время критических простоев** (в минутах)
2. **Автоматическая отправка E-mail:**
   - При нажатии кнопки **«Подтвердить и отправить рапорт»** система генерирует сводное HTML-письмо на почту директора завода.
3. **История и Аналитика:**
   - Сохранение истории рапортов в базе Odoo с отслеживанием изменений через Chatter.
   - Сводные отчеты в виде Pivot-таблиц и интерактивных графиков (Graph View).

## 🛠️ Структура модуля

- `models/shift_summary_report.py`: Основная бизнес-логика и формулы расчета метрик.
- `data/mail_template_data.xml`: HTML-шаблон электронного письма директору.
- `views/shift_summary_report_views.xml`: Представления Tree, Form, Pivot, Graph и меню Производства.
- `security/ir.model.access.csv`: Правила доступа для пользователей и менеджеров.
- `tests/test_shift_summary_report.py`: Набор модульных тестов.
