# Odoo — Учёт простоев оборудования (Equipment Downtime Tracking)

Модуль для Odoo 19, позволяющий отслеживать простои оборудования (рабочих центров) в производстве, вести справочник причин простоев, рассчитывать OEE и формировать отчёты для директора завода.

---

## 🚀 Быстрый запуск

### 1. Подготовка окружения
Скопируйте файл конфигурации окружения:
```bash
cp env.sample .env
```

### 2. Запуск Docker-контейнеров
Запустите сервисы Odoo и PostgreSQL в фоновом режиме:
```bash
docker compose up -d
```

### 3. Откройте Odoo в браузере
Перейдите по адресу: [http://localhost:8069](http://localhost:8069)

---

## 📦 Активация и установка кастомного модуля

1. **Включите режим разработчика (Developer Mode):**
   * Перейдите в **Настройки** (**Settings**).
   * Прокрутите вниз и нажмите **Активировать режим разработчика** (**Activate the developer mode**).
2. **Обновите список приложений:**
   * Перейдите в раздел **Приложения** (**Apps**).
   * В верхнем меню нажмите **Обновить список приложений** (**Update Apps List**) $\rightarrow$ **Update**.
3. **Установите модули:**
   * В строке поиска приложений **снимите фильтр «Приложения» / «Apps»** (нажмите `x`).
   * Для учета простоев найдите: `Equipment Downtime` и нажмите **Установить** (**Install**).
   * Для отчетов смены найдите: `Shift Summary Report for Director` и нажмите **Установить** (**Install**).

## 🏭 Отчет по загрузке оборудования для директора завода (User Story №5)

Позволяет директору завода анализировать простаивающее оборудование за месяц и устранять «узкие места» в производстве:
- **Месячный отчет по загрузке оборудования:** Открывается в меню **Производство** $\rightarrow$ **Отчеты** $\rightarrow$ **Отчет по загрузке оборудования** (включает гистограмму загрузки, Pivot-таблицу и фильтр «Текущий месяц»).
- **Интерактивная диаграмма причин (Pie Chart):** При выборе станка или нажатии на смарт-кнопку **«Причины простоя (%)»** / **«Диаграмма причин простоя»** открывается круговая диаграмма с процентным распределением причин остановок (например, «Поломка»: 30.0%, «Нет заготовок»: 70.0%).

---

## 📈 Модуль «Сводный рапорт смены для директора» (Shift Summary Report)

Позволяет автоматически формировать и отправлять сводные отчёты смены директору завода с ключевыми аналитическими показателями:
- **Общий объем выпуска деталей** (шт.)
- **Процент брака за день** (%)
- **Время критических простоев** (мин.)
- **Коэффициент выполнения плана** (%)

**Использование:**
* **Производство** $\rightarrow$ **Операции** $\rightarrow$ **Рапорты смен**
* При нажатии **«Подтвердить и отправить рапорт»** документ меняет статус на *Confirmed*, заносится в историю и автоматически отправляет сверстанное E-mail письмо директору завода.

## 📊 Загрузка демонстрационных данных

При установке или обновлении модуля автоматически сидируются тестовые данные:
- **Рабочие центры (`mrp.workcenter`):** `CNC-01` (Токарный станок ЧПУ), `MILL-01` (Фрезерный станок), `ASSY-01` (Участок сборки).
- **Причины простоев (`downtime.reason`):** Поломка станка, Ожидание металла, Нет электричества.
- **Записи о простоях (`equipment.downtime`):** Примеры простоев за текущий месяц (30% поломка, 70% ожидание металла).

## 🛠️ Как использовать функционал модуля

После установки откройте приложение **Производство** (**Manufacturing**):

1. **Отчет по загрузке оборудования (для директора):**
   * **Производство** $\rightarrow$ **Отчеты** $\rightarrow$ **Отчет по загрузке оборудования**
2. **Записи о простоях (Downtime Records):**
   * **Производство** $\rightarrow$ **Операции** $\rightarrow$ **Downtime Records**
3. **Справочник причин простоев:**
   * **Производство** $\rightarrow$ **Настройки** $\rightarrow$ **Downtime Reasons**
4. **Рабочие центры (Work Centers):**
   * **Производство** $\rightarrow$ **Настройки** $\rightarrow$ **Рабочие центры**
   * В форме каждого рабочего центра доступна кнопка **«Диаграмма причин простоя»**, смарт-кнопка **«Причины простоя (%)»** и вкладка **«Downtimes»** со статистикой.
